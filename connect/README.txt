Connect BSE to Claude
=====================

Mac:     double-click "Connect BSE to Claude.command"
         (first time only: if macOS says it's from an unidentified developer,
          right-click the file > Open > Open)

Windows: double-click "Connect BSE to Claude.bat"
         (if SmartScreen warns: More info > Run anyway)

It installs bse-mcp, adds it to Claude Desktop (your other Claude settings are
kept; the old config is saved as claude_desktop_config.json.bak), and restarts
Claude Desktop so the BSE tools appear. Run it again any time to upgrade.

Then ask Claude, for example:
  What's ABB India's latest quarterly result and how does it compare with last year?

Unofficial; not affiliated with BSE. https://github.com/goransh-gattani/bse-mcp
